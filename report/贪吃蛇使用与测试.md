# 贪吃蛇：运行与测试

## 环境

- Python 3，且安装包含 tkinter / Tcl/Tk。
- 使用 Windows、macOS 或 Linux 图形桌面。
- 不依赖 pygame 或其他第三方包。
- 本项目实际验证环境：Windows、Python 3.14.5、Tk 8.6。

以下命令均在项目根目录运行。

## 运行

```powershell
python code/snake.py
```

Windows 中如果 `python` 命令不可用，可以改用：

```powershell
py code/snake.py
```

游戏启动后自动向右移动，每 140 毫秒前进一格。亮绿色为蛇头，
绿色为蛇身，粉色圆点为食物。吃到一个食物得 1 分、增长一格。
撞墙或撞到身体则结束；填满棋盘则通关。

| 操作 | 功能 |
| --- | --- |
| ↑ ↓ ← → | 改变方向；禁止直接掉头 |
| 空格 / 暂停按钮 | 暂停或继续 |
| R / 回车 / 重新开始按钮 | 重置蛇、分数和食物 |
| Esc / 窗口关闭按钮 | 退出 |

一次移动前只接收第一次有效转向。比如向右时快速按“上、左”，
本次只向上，下一次移动后才能再次转向。

## 自动化测试

```powershell
python -m unittest discover -s tests -v
```

预期结尾显示 `Ran 13 tests` 和 `OK`。测试无需打开游戏窗口。
测试使用独立实例和固定随机种子，不会改动任何现有文件或数据。

覆盖内容：初始化与棋盘尺寸、移动、吃食增长与食物位置、四面墙、
身体碰撞、进入正在离开的尾巴格、掉头和快速按键限制、暂停恢复、
结束后停止响应、重开清除状态，以及填满棋盘获胜。

## 手动测试

| 步骤 | 预期结果 |
| --- | --- |
| 启动游戏，依次按方向键转弯 | 蛇连续移动，蛇头颜色更亮 |
| 向右移动时按左键 | 继续向右，不直接掉头 |
| 在一次移动间隔内快速按上、左 | 只接受向上，避免瞬间掉头 |
| 引导蛇吃到粉色食物 | 得分增加 1，长度增加 1，食物出现在空格 |
| 按空格，等待两秒，再按空格 | 暂停时棋盘不动且显示“已暂停”，恢复后继续移动 |
| 点击暂停按钮，再按空格 | 恢复一次，不因按钮焦点而重复切换 |
| 不操作，等待撞墙 | 显示“游戏结束”，蛇停止移动 |
| 重开并吃几个食物后，转弯撞到自己的身体 | 显示“游戏结束” |
| 在运行、暂停和结束状态分别按 R 或回车 | 得分归零，蛇恢复三格并向右移动，遮罩消失 |
| 多次点击重新开始 | 每次重置，移动速度保持不变 |
| 按 Esc；重新启动后点击窗口关闭按钮 | 窗口关闭，终端返回且没有异常 |

填满棋盘的胜利条件由自动化测试直接构造局面验证，无需手动长时间游玩。

## 常见问题

- `No module named tkinter`：Windows 的 Python 安装程序中启用 Tcl/Tk 组件；
  Linux 安装发行版对应的 Tk 包（例如 Ubuntu 的 `python3-tk`）。
- 提示无法创建窗口：请在图形桌面终端运行，纯命令行服务器通常没有图形显示环境。
- 方向键无响应：先点击游戏窗口使其获得焦点。
- 调整难度：修改 `SnakeApp.TICK_MS`，值越大移动越慢；
  调整 `SnakeGame()` 的 `width`、`height` 可更改棋盘大小。
